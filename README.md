# トキノート

中学受験の問題集PDFを、iPadで手書きして解くための学習アプリです。
解く → ⭕🔺❌で丸つけ → 間違えた問題だけを日をあけて出し直す、までを1つにまとめています。

- 種類：画面はビルド不要の静的Webアプリ（`public/index.html`）。保存と見守りは Cloudflare Workers ＋ Durable Objects
- 想定端末：iPad（Safari）＋ Apple Pencil。PCやスマホのブラウザでも動きます
- 公開先：Cloudflare Workers（家族のパスコード4けたで入る）。claude.ai のアーティファクトでも動きます（見守りなし）

## 機能

| 分類 | 内容 |
|---|---|
| 書く | ペン（筆圧対応・16色＋好きな色）、マーカー（10色＋好きな色）、消しゴム、元に戻す／やり直し |
| 書きやすさ | 書き終わりでペンを0.6秒止めると、直線か、まる（だ円）に整う。➰かこむ（投げ縄）で、書いたものの移動・拡大・複製・削除。🔤文字（キーボードで入力） |
| 表示 | ピンチで0.5〜10倍。大きく拡大したときは見えている部分だけを高画質で描き直す。ページの回転（90°ずつ） |
| 丸つけ | ⭕🔺❌スタンプ（もう一度タップで取り消し）、❌🔺のあとに理由（計算ミス／読みまちがい／知らなかった／時間切れ） |
| 問題わく | 1問ずつ囲むと、その問題だけを切り出して復習に出す。⋯ →「🔍 問題を自動で見つける」で、PDFの文字（問1・(2)・①・［3］など）から自動で作れる（段組み対応、「解答」ページは除外、スキャンPDFは不可） |
| 復習 | ❌🔺の問題を「すぐ→3日後→1週間後→1か月後」に再出題。全部⭕で🏆卒業 |
| すきま | ↕️で問題と問題のあいだをタップすると、そこでページが分かれて方眼の書くスペースが入る。タップで広さ変更・削除（子どもごと・ページごと）。見守り画面からも入れられ、子どもの画面にも入る |
| スタンプ | 🌟で、ほめる・きもち・どうぶつ・しるし・ことば（文字スタンプ）の80種類をはれる。大きさ3段階、文字スタンプは5色 |
| その場の声かけ | 見守り画面から 👏リアクション（子どもの画面で大きく演出）、👆ここ見て（その場所が光る）、💮はなまる（子どもに+10🪙、1つにつき1回） |
| 赤シート | 「赤シート用」オレンジで書いた字と、印刷された赤字を隠す。上下に動かせる |
| 穴うめ | 囲んだ所をグレーで隠し、タップで開く |
| メモ | 📝で出す計算用紙。移動・大きさ変更ができ、ページごとに保存。見守り中は、どちらかが開くと相手の画面でも開き、おうちの人の書きこみも重なって見える |
| ごほうび | 丸つけと勉強時間でコインがたまり、ごほうびと交換（おうちの人のパスコード）。100コインごとにシール |
| 記録 | 今日の⭕🔺❌、勉強時間、連続日数。子ども2人分を切り替え |
| 見守り | 別の端末で、子どもが書いている線・丸つけ・メモ・開いているページをリアルタイムに表示（Cloudflare版） |
| 解説の録画 | 見守り画面の🎬で、ホワイトボードに書きながら話した様子（声＋書いた順番、最大5分）を録画して送る。ペン・マーカー（筆圧、止めるとまっすぐ／まる）・消しゴム・かこむ（移動・拡大・複製・削除）・文字・スタンプ・2本指ズーム。ボードには、ページ全体・登録した問題・指で囲んだ範囲（子どもの書きこみ込みも可）・写真をのせられる。子どもは再生・一時停止・10秒戻し・1.5/2倍速・ズームで見られる |
| 動画 | 見守り画面の🎥で、画面収録やカメラの動画（60MBまで）を送る。子どもはタップで再生。消すとクラウドからも消える |
| アドバイス | 見守り画面から、手書き・文字・画像・音声（最大2分）でアドバイスを書き込み、子どもの画面にリアルタイムで重ねて表示。子どもは消せず、💬で一時的に隠せる。画像はタップで拡大 |
| 答え | 📖で答えのページを横（または下）に並べて表示。答えは同じPDFのうしろでも別のPDFでもよく、◀▶で合わせると問題ページごとに覚える。⋯ でパスコード必須にできる（10分有効） |
| しつもん | 子どもが🙋で「このまま／文字／声」でしつもん → おうちの人のスマホに通知。通知を開くとそのページの見守りが始まり、子どもに「見てくれています」と出る（Cloudflare版・ホーム画面に追加した端末） |
| その他 | ツールバーを隠す、全ページの書き込みを消して解き直し、バックアップの保存と復元 |

## ファイル構成

```
public/index.html          アプリ本体（HTML・CSS・JavaScript）
public/vendor/             PDF.js 4.10.38（legacy版）
public/cmaps.json          日本語PDF用の文字対応表（PDF.js の cmaps を1ファイルにまとめたもの）
worker/index.js            Cloudflare Worker と Durable Object「Family」
public/sw.js               通知の受け取り・オフライン用の保存
public/manifest.webmanifest, icon-*.png  ホーム画面に追加したときの名前とアイコン
wrangler.jsonc             Cloudflare の設定
licenses/                  同梱ライブラリのライセンス
```

## データの保存先

| データ | Cloudflare版 | claude.ai版 |
|---|---|---|
| 問題集のPDF | 端末（IndexedDB）＋ Durable Object（1MBずつに分けて保存、95MBまで） | 端末だけ |
| 書き込み・丸つけ・メモ・問題わく・穴うめ・回転・記録・ごほうび | 端末 ＋ Durable Object | 端末 ＋ アーティファクトDB（ユーザーごとの非公開領域） |
| おうちの人のパスコード（ごほうび交換用） | 端末だけ | 端末だけ |

- PDFは SHA-256 のハッシュで識別します。同じPDFなら、どの端末でも同じ書き込みにつながります。
- どちらの場所でもない環境（ただの静的サーバー）では、端末保存だけで動きます。⋯ メニューの「バックアップを保存」を定期的に使ってください。

## Cloudflare への置き方（初回だけ・PCで）

1. Cloudflare ダッシュボード → Workers & Pages → 作成 → 「Gitリポジトリをインポート」で `avenirplus/tokinote` を選ぶ
   - 設定はそのままでOK（`wrangler.jsonc` を読み込んで `npx wrangler deploy` が走ります）
2. できた Worker「tokinote」→ 設定 → 変数とシークレット → **シークレット** `APP_PIN` に4けたの数字を登録して、デプロイし直す
3. 表示された `https://tokinote.<アカウント名>.workers.dev` を iPad で開き、パスコードを入れる

以後は、GitHub の `main` を更新すると自動で反映されます。

### 入口のパスコード（APP_PIN）について

- パスコードは Cloudflare のシークレットにだけ置きます。ソースやチャットには書きません。
- まちがいが5回続くと、その回線からは1分、2分、4分…（最大1日）入れなくなります。全体でも1日100回までです。
- 一度入れた端末は180日間ログインしたままです。パスコードを変えたときは、Worker の `api/logout-all` で全端末をログアウトできます。

### 無料枠の目安

Durable Objects（SQLite）は Workers Free プランで使えます。上限を超えた場合はエラーで止まるだけで、課金はされません。家庭で使う量なら無料枠に収まる見込みです。

### しつもん通知（保護者のiPhone）

1. iPhoneのSafariでトキノートを開き、共有ボタン →「ホーム画面に追加」
2. ホーム画面のトキノートから開いてパスコードを入れる
3. 本棚の「🔔 しつもん通知をこの端末で受け取る」→ 通知を許可
4. ⋯ →「🔔 通知のテスト」で届くか確認

通知はWeb Push（VAPID方式）。鍵はDurable Objectの中で自動生成され、外部サービスや追加料金は使わない。通知には中身を入れず、端末がログイン済みの状態で `/api/q/latest` を取りに行く。

## 動かし方（開発）

```
npm i -g wrangler        # または npx wrangler
echo "APP_PIN=1234" > .dev.vars
wrangler dev             # → http://localhost:8787/
```

画面だけを確かめるなら `cd public && python3 -m http.server 8000` でも動きます（端末保存のみ）。

## 設計メモ

- **座標**：書き込みはPDFの元の向きで、ページ幅=10000 の座標で保存します。回転や拡大は表示の時だけ反映するので、向きや倍率を変えても位置がずれません。
- **復習の間隔**：`INTERVALS = [3, 7, 30]`（日）。❌🔺のあと⭕が続くごとに次の間隔へ進み、最後まで⭕で卒業です。
- **コイン**：⭕10・🔺5・❌2（同じ問題は1日1回まで）、復習⭕15、卒業30、10分勉強ごとに10（1日60まで）。丸つけの記録から毎回計算し直すため、取り消すと減ります。
- **Apple Pencil**：Pencilを初めて検出すると「Pencilで書く・指はスクロール」に自動で切り替わります（⋯で変更可）。
- **見守り**：WebSocket（Durable Object のハイバネーションAPI）で中継します。書いている途中の線は0.08秒ごと、書き終えたページは丸ごと送ります。見守る端末は書き込めません（保存も送信もしない）。
- **アドバイス層**：子どもの書き込み（`ln_<子>_<本>/ink/p<n>`）とは別の `ln_<子>_<本>/adv/p<n>` に保存するので、同時に書いても上書きし合いません。画像は端末で長辺1600pxのJPEGに縮めてから `/api/blob/:id` に置きます。
- **解説の録画**：画面を動画にせず、線の座標と時刻（ミリ秒）＋音声を保存し、再生時に音声の再生位置に合わせて線を描き直します。データは `lec_<id>`（JSON）と `/api/blob`（音声・下じき画像）。
- **動画**：1MBずつ `PUT /api/blob/:id/part/:n` で送り、`POST /api/blob/:id/done` で件数と大きさを確かめて完成。取り出しは1MBずつ流すので、Worker のメモリを使いすぎません。子どもの端末では一度読んだ動画を保存し、2回目からはすぐ再生します。
  - Durable Objects の保存容量（無料枠）を使うので、見終わった動画は消すのがおすすめです。
- **すきま**：ページごとに `gaps:[{y, h}]`（元のページの座標）を書き込みと一緒に保存。書き込みは「すきま込みの座標」、問題わく・穴うめは元のページの座標のままで、表示のときに変換します。PDFはすきまで区切って描きます。
- **保存のタイミング**：端末には書いた瞬間に保存し、クラウドへは少しまとめて送ります。アプリを閉じる・切りかえるときは、待っている送信をすぐ実行します。
- **途中の線の後始末**：書き終えたら、まだ送っていない途中の線を捨てて `liveEnd` を送ります。受け取った側は、`liveEnd` か4秒の無通信で途中の線を消します（遅れて届いた途中の線が残る不具合の対策）。
- **API**：`/api/health`・`/api/login`・`/api/kv`（キーごとのJSON）・`/api/kv/list`・`/api/pdf/:id`・`/api/blob/:id`（画像・音声・動画。`/part/:n`・`/done`・DELETE）・`/api/live`（WebSocket）。`/api/health` と `/api/login` 以外はログインが必要です。
